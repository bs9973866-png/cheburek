# Cheburek Access — инструкция на русском

## Что это

Cheburek Access — Windows GUI для запуска официального ядра sing-box с пользовательским профилем подключения и выборочной маршрутизацией доменов. В программе нет встроенных платных серверов, аккаунтов, скрытых туннелей или телеметрии.

**Это первая версия, а не полноценный VPN/TUN-клиент.** Она поднимает локальный mixed proxy на 127.0.0.1:2080 и может включить системный прокси Windows. Приложения, которые игнорируют системные настройки, потребуется настраивать отдельно. Программа не гарантирует доступность всех сервисов во всех сетях.

## Сборка

Открой вкладку Actions в GitHub и выбери запуск **Build Windows app**. После успешного выполнения открой workflow run → Artifacts → CheburekAccess-Windows-x64 и скачай CheburekAccess.exe.

Сборка также запускается автоматически после изменений app.py, workflow или requirements.txt в ветке main.

## Первый запуск

1. Скачай и распакуй артефакт, затем запусти CheburekAccess.exe.
2. Нажми **Установить sing-box**. Программа скачивает последний стабильный архив с официального GitHub-проекта SagerNet/sing-box и проверяет SHA-256 по digest из API релиза.
3. Получи прокси-конфигурацию у провайдера, которому доверяешь, или используй собственный сервер. Поддерживаются ссылки vless://, vmess://, trojan://, ss:// и полный sing-box JSON.
4. Вставь ссылку в поле или импортируй JSON.
5. Выбери сервисы, которые нужно отправлять через прокси. Остальной трафик маршрутизируется напрямую. Можно добавить свои домены через запятую.
6. Нажми **Подключить**. Перед запуском конфиг проверяется командой sing-box check.
7. Для отключения нажми **Отключить** — процесс будет остановлен, а прежние параметры системного прокси восстановлены.

## Настроенные группы доменов

- OpenAI / ChatGPT / Codex (не обходит проверку телефона, ограничения аккаунта или политику доступности OpenAI).
- Claude
- Gemini
- Perplexity
- Telegram
- WhatsApp
- YouTube

Это стартовые списки доменов, а не обещание, что любой сервис заработает. Некоторые приложения используют отдельные IP-адреса, QUIC/UDP, свои прокси-настройки или дополнительные домены. Для них могут потребоваться отдельные настройки или обновление правил.

## Безопасность

- Не импортируй профиль от незнакомых людей: прокси-сервер видит адреса назначения и метаданные соединений, а его оператор может вести логи.
- Не вставляй в публичный репозиторий ссылки с секретными UUID/паролями. Активный конфиг хранится только в профиле пользователя Windows под %LOCALAPPDATA%\CheburekAccess.
- Проект не подменяет номер телефона, SMS/WhatsApp-код, cookies, токены и не обходит проверку аккаунта.
- Код программы открытый. Ядро sing-box загружается с официального репозитория и проверяется по опубликованному GitHub digest.
- Используй приложение и сетевые профили с учётом правил и законов, применимых к тебе.

## Запуск из исходников

Windows, Python 3.11+:

~~~powershell
py -m pip install -r requirements.txt
py app.py
~~~

Для локальной сборки:

~~~powershell
py -m pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name CheburekAccess app.py
~~~
